## 更新内容

- 合并上游 KikoFlu v3.8.0 版本。

## 功能改动

- 新增对 HarmonyOS API 22 设备的支持。
- 新增 HarmonyOS 原生沉浸光感顶栏和底栏，并适配主页、搜索、“我的”页面及 MiniPlayer。
- HarmonyOS 新安装默认开启沉浸光感顶栏和底栏，仍可在实验性功能中分别关闭。
- 新增 HarmonyOS 系统播放器歌词和桌面悬浮歌词显示。

## Bug 修复

- 修复新版 Flutter OHOS 工具链下的兼容问题。
- 修复重复点击“作品”或“我的”导航标签时，刷新与回到顶部行为失效的问题。
- 修复播放页悬浮歌词按钮在 HarmonyOS 上无响应的问题。
- 修复沉浸光感模式下瀑布流滚动、排序弹窗层级与性能、刷新指示器位置及键盘遮挡相关问题。
- 修复主页、搜索及“我的”等页面的原生顶栏按钮无响应问题。
- 修复开启沉浸光感底栏后，进入作品详情页的转场动画与普通模式不一致的问题。
