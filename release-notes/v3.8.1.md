## 更新内容

- 合并上游 KikoFlu v3.8.1 版本。

## 功能改动

- 新增对 HarmonyOS API 22 设备的支持。
- 将 HarmonyOS 顶栏、底栏及 MiniPlayer 的液态玻璃表面替换为统一的轻量透明磨砂材质。
- 新增 HarmonyOS 系统播放器歌词和桌面悬浮歌词显示。

## Bug 修复

- 修复新版 Flutter OHOS 工具链下的兼容问题。
- 修复重复点击“作品”或“我的”导航标签时，刷新与回到顶部行为失效的问题。
- 修复有字幕时偶发提示设备不支持，以及手动关闭系统悬浮字幕后应用内状态未归位的问题。
- 修复播放后切到后台时，HarmonyOS 系统播放器偶发不显示的问题。
- 改善 HarmonyOS 玻璃导航模式下的滚动性能、页面转场与顶栏透明度一致性。
- 修复输入法弹出后 MiniPlayer 未隐藏的问题。
- 优化主页顶部筛选胶囊的宽度分配与切换动画。
